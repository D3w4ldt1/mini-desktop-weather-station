# Mini Desktop Weather Station

A compact desktop weather station designed to display real-time environmental information in a simple, easy-to-read format.

## Features

* Real-time temperature monitoring
* Compact desktop-sized design
* Digital display
* Sensor-based environmental readings
* Arduino/ESP32-based control system
* Designed to be simple, portable, and low-cost

## Hardware

* Microcontroller
* Temperature/environmental sensor
* Display
* Jumper wires
* Breadboard or custom wiring
* USB power supply
* 3D-printed or otherwise fabricated enclosure

## How It Works

The environmental sensor collects temperature data and sends the readings to the microcontroller. The microcontroller processes the data and displays it on the screen.

The goal is to create a small standalone device that can continuously monitor the surrounding environment without needing a computer.

## Software

The project is programmed using Arduino-compatible software.

### Main Components

* Arduino IDE
* C/C++
* Microcontroller firmware
* Sensor libraries
